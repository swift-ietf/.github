# Swift IETF

Use this organization when you need a Swift implementation of an IETF RFC. There is one package per specification, named `swift-rfc-<number>`, which follows its source document as literally as possible under its own namespace, such as `RFC_3986`. To check whether an RFC is covered, search its number in the [repositories](https://github.com/orgs/swift-ietf/repositories). If several specifications govern your subject, use the unifying `swift-*-standard` package in [swift-standards](https://github.com/swift-standards). This is part of Layer 3 of the [Swift Institute](https://github.com/swift-institute).

> Swift IETF is an independent open-source project. It is not affiliated with, endorsed by, or sponsored by the Internet Engineering Task Force.
